# Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a live transaction dashboard at `/` and a `GET /api/v1/trace/{transactionId}` endpoint that shows every Camel pipeline step for a transaction.

**Architecture:** A single `index.html` served by `platform-http` from `META-INF/resources/`. A new `direct:rest-trace` sub-route in `RestApiRoute` queries the Camel `BacklogTracer` and returns steps as JSON. `IsoDispatcher` is updated to tag the async exchange with a `txId` header so the BacklogTracer XML includes the UUID in every step of both the REST and the ISO 8583 send exchanges, making per-transaction filtering reliable.

**Tech Stack:** Quarkus 3.27, Apache Camel 4.14, `org.apache.camel.spi.BacklogTracer`, vanilla HTML/CSS/JS (no framework, no CDN, no build step).

**Key packages:** `id.redhat.razhari` under `src/main/java/`.

**How BacklogTracer works:**
- Enabled only in dev: `%dev.camel.main.backlog-tracing=true` in `src/main/resources/application.properties`.
- Access: `camelContext.getExtension(BacklogTracer.class)` returns `null` when not enabled (test profile) — always null-check it.
- `BacklogTracer.dumpAllTracedMessages()` returns `List<BacklogTracerEventMessage>`.
- `BacklogTracerEventMessage` interface (package `org.apache.camel.spi`): `getUid()` (long, monotonically increasing), `getRouteId()`, `getToNode()`, `getTimestamp()` (String ISO-8601), `getMessage()` (XML string including headers and body).
- The XML looks like: `<message ... route="..." node="..."><headers><header key="txId" ...>UUID</header></headers><body type="...">...</body></message>`

**Correlation strategy:**
- E1 (`direct:rest-submit`): the body after processing is `{"transactionId":"<UUID>"}` — UUID appears in the XML body.
- E2 (`direct:send-iso8583`): body is `TransactionState` (default `toString()` doesn't include UUID). Fix: `IsoDispatcher` passes `txId` as a header via `asyncSendBodyAndHeaders()` — Camel propagates headers throughout E2, so UUID appears in every BacklogTracer step.
- Filter: `m.getMessage().contains(transactionId)` catches both exchanges.

**Static file serving:** Quarkus serves `src/main/resources/META-INF/resources/` at `/` automatically when `platform-http` is on the classpath. No configuration needed.

```java
package id.redhat.razhari.route;

import id.redhat.razhari.model.TransactionState;
import jakarta.enterprise.context.ApplicationScoped;
import jakarta.inject.Inject;
import org.apache.camel.ProducerTemplate;

import java.util.Map;

/**
 * Application-scoped wrapper around ProducerTemplate for dispatching
 * outbound ISO 8583 messages. Being ApplicationScoped allows this bean
 * to be mocked via @InjectMock in @QuarkusTest — ProducerTemplate itself
 * is @Dependent and cannot be mocked directly.
 *
 * The txId header is set so BacklogTracer XML includes the UUID in every
 * step of the send-iso8583 exchange, enabling per-transaction filtering.
 */
@ApplicationScoped
public class IsoDispatcher {

    @Inject
    ProducerTemplate producerTemplate;

    public void dispatch(TransactionState state) {
        producerTemplate.asyncSendBodyAndHeaders(
            "direct:send-iso8583",
            state,
            Map.of("txId", state.id)
        );
    }
}
```

```java
// Trace: returns all BacklogTracer steps for a given transaction UUID
from("direct:rest-trace")
    .routeId("rest-trace")
    .process(exchange -> {
        String txId = exchange.getIn().getHeader("transactionId", String.class);
        BacklogTracer tracer = (BacklogTracer) camelContext.getExtension(BacklogTracer.class);
        List<TraceStep> steps;
        if (tracer == null) {
            steps = Collections.emptyList();
        } else {
            AtomicInteger counter = new AtomicInteger(1);
            steps = tracer.dumpAllTracedMessages().stream()
                .filter(m -> m.getMessage() != null && m.getMessage().contains(txId))
                .sorted(java.util.Comparator.comparingLong(BacklogTracerEventMessage::getUid))
                .map(m -> toTraceStep(m, counter.getAndIncrement()))
                .collect(Collectors.toList());
        }
        exchange.getMessage().setBody(steps);
        exchange.getMessage().setHeader(Exchange.CONTENT_TYPE, "application/json");
    })
    .marshal(json());
```

Add these two helper methods and constants after the existing `toResponse()` method (before the closing `}` of the class):

```java
private static final Pattern PAN_PATTERN =
    Pattern.compile("(\\d{6})\\d{3,9}(\\d{4})");
private static final Pattern BODY_TYPE_PATTERN =
    Pattern.compile("<body[^>]+type=\"([^\"]+)\"");

private TraceStep toTraceStep(BacklogTracerEventMessage msg, int step) {
    TraceStep ts = new TraceStep();
    ts.step      = step;
    ts.routeId   = msg.getRouteId();
    ts.node      = msg.getToNode();
    ts.timestamp = msg.getTimestamp() != null ? msg.getTimestamp().toString() : null;

    String raw = msg.getMessage() != null ? msg.getMessage() : "";

    Matcher typeMatcher = BODY_TYPE_PATTERN.matcher(raw);
    ts.bodyType = typeMatcher.find()
        ? typeMatcher.group(1).replaceAll(".*\\.", "")
        : "Object";

    String masked = PAN_PATTERN.matcher(raw).replaceAll("$1******$2");
    ts.bodySummary = masked.length() > 200 ? masked.substring(0, 197) + "..." : masked;
    return ts;
}
```

**IMPORTANT — if `BacklogTracerEventMessage` import fails:** In Camel 4.x the class may be in a different package. Try these alternatives in order:
1. `org.apache.camel.spi.BacklogTracerEventMessage` (Camel 4.x)
2. `org.apache.camel.api.management.mbean.BacklogTracerEventMessage` (Camel 3.x compat)

If neither compiles, use a raw wildcard: replace `BacklogTracerEventMessage::getUid` with a lambda:
```java
.sorted((a, b) -> Long.compare(a.getUid(), b.getUid()))
```

```html
<script>
  const BASE = '/api/v1';
  const POLL = 2000;
  const SYM  = { '840': '$', '978': '€' };

  let expandedId = null;
  let traceCache = {};
  let lastTxs    = [];

  function shortId(id) { return id ? id.slice(0, 8) + '…' : '—'; }
  function fmtTime(iso) {
    if (!iso) return '—';
    try { return new Date(iso).toLocaleTimeString(); } catch { return iso; }
  }
  function fmtAmt(tx) {
    if (!tx.request) return '—';
    const s = SYM[tx.request.currency] || (tx.request.currency + ' ');
    return s + (tx.request.amount / 100).toFixed(2);
  }

  function renderTrace(steps) {
    if (!steps || !steps.length)
      return '<div class="trace-empty">No trace data. BacklogTracer requires dev profile (<code>./mvnw quarkus:dev</code>).</div>';
    return steps.map(s => `
      <div class="step">
        <div class="step-head">
          <span class="step-num">Step ${s.step}</span>
          <span class="step-route">${s.routeId || '—'}</span>
          <span class="step-node">${s.node || '—'}</span>
          <span>${fmtTime(s.timestamp)}</span>
        </div>
        <div class="step-body"><span class="step-type">[${s.bodyType}]</span> ${escHtml(s.bodySummary)}</div>
      </div>`).join('');
  }

  function escHtml(s) {
    return (s || '').replace(/&/g,'&amp;').replace(/</g,'&lt;').replace(/>/g,'&gt;');
  }

  function buildRows(txs) {
    if (!txs.length) return '<div class="empty">No transactions yet. Start the app in dev mode and wait ~4s for seed data.</div>';
    return '<table><thead><tr><th>ID</th><th>Status</th><th>Amount</th><th>Updated</th></tr></thead><tbody>' +
      txs.map(tx => {
        const exp = tx.transactionId === expandedId;
        let rows = `<tr class="tx-row${exp?' expanded':''}" data-id="${tx.transactionId}">
          <td class="id-col">${shortId(tx.transactionId)}</td>
          <td><span class="badge ${tx.status}">${tx.status}</span></td>
          <td class="amt-col">${fmtAmt(tx)}</td>
          <td class="upd-col">${fmtTime(tx.updatedAt)}</td>
        </tr>`;
        if (exp) {
          const steps = traceCache[tx.transactionId];
          rows += `<tr class="trace-row"><td colspan="4">
            <div class="trace-wrap">${steps ? renderTrace(steps) : '<div class="trace-empty">Loading trace…</div>'}</div>
          </td></tr>`;
        }
        return rows;
      }).join('') +
    '</tbody></table>';
  }

  function render() {
    document.getElementById('app').innerHTML = buildRows(lastTxs);
    document.querySelectorAll('.tx-row').forEach(row => {
      row.addEventListener('click', () => {
        const id = row.dataset.id;
        if (expandedId === id) {
          expandedId = null;
          render();
        } else {
          expandedId = id;
          if (traceCache[id] !== undefined) {
            render();
          } else {
            render(); // show "Loading…" immediately
            fetch(`${BASE}/trace/${id}`)
              .then(r => r.json())
              .then(steps => { traceCache[id] = steps; render(); })
              .catch(() => { traceCache[id] = []; render(); });
          }
        }
      });
    });
  }

  async function refresh() {
    try {
      const r = await fetch(`${BASE}/transactions`);
      if (!r.ok) throw new Error(r.status);
      lastTxs = await r.json();
      document.getElementById('live').className = 'live';
      render();
    } catch {
      document.getElementById('live').className = 'live offline';
    }
  }

  refresh();
  setInterval(refresh, POLL);
</script>
```
